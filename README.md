# 油站库存与配送闭环

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则验证：`npm run verify`（在 Node 中用真实 Pinia store 跑闭环用例）

数据保存在浏览器 localStorage（key：`hxwlfront-19-oil-delivery-v2`），刷新页面后罐容、在库量、占用量与配送状态保持一致，方便后续扩展接口、权限、图表或地图能力。

## 闭环规则

### 油罐台账（油站 × 油品）

- 每个油站按油品维护一罐，可在台账表中调整**罐容**。
- **在库量 = 期初库存 + 已到站累计吨数**，只随「确认到站」增加。
- **占用量 = 该油品「待发车」+「运输中」单据的计划量之和**。
- **剩余罐容 = 罐容 − 在库量 − 占用量**。
- 罐容下调不得低于「在库 + 占用」，否则拒绝保存。

### 配送单状态机

```
待发车 ──发车──▶ 运输中 ──确认到站──▶ 已到站（终态，吨数入库，记录封存）
  │                 │
  └─────取消────────┴──▶ 已取消（终态，释放占用额度，库存不变）
```

- **新建**：吨数必须大于 0，且不得超过该油站该油品的剩余罐容（待发车与运输中均已计入占用）。
- **发车**：只有「待发车」可进入「运输中」，其他状态一律拒绝。
- **到站**：只有「运输中」可确认到站；到站后释放占用，吨数进入在库量。
- **取消**：仅「待发车 / 运输中」可取消并释放额度；**已到站记录不能作废回退库存**，界面不提供删除入口。
- 每次流转写入事件轨迹（创建 / 发车 / 到站 / 取消时间）。
