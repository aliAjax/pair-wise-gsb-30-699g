# 油品配送计划

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

油站库存闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 库存闭环规则

- 每个油站按油品维护罐容和在库量，看板实时展示在库、占用与剩余可配送额度。
- 新建配送单不得超过剩余罐容：剩余额度 = 罐容 - 在库量 - 占用量。
- 同一油品下，待发车与运输中的配送单计划量都计入占用。
- 状态机单向流转：只允许待发车 → 运输中，只有运输中可确认到站。
- 确认到站后释放占用，并把吨数计入该油站该油品的在库量。
- 取消未到站（待发车/运输中）配送单立即释放占用额度；已到站记录不可作废，不能借此回退库存。
- 罐容/在库量可在线维护，但「在库量 + 占用量 ≤ 罐容」始终受校验保护。
- 罐容、在库量、占用量与配送状态整体持久化，刷新后保持一致。
